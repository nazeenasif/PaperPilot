# PaperPilot

PaperPilot: an AI research assistant that answers questions about research papers with verified citations that open the exact PDF passage.

## Evaluation results

<!-- eval-results:start -->
Retrieval quality on PaperPilot's golden set, generated by `python -m evaluation report` (details in [eval/results.md](eval/results.md)). 0 model requests.

**Conclusion**: Adding the paper title and section to each passage before embedding gave the best single improvement (MRR 0.31 → 0.41, hit@1 0.20 → 0.30) at no runtime cost. Combined with hybrid BM25 + vector search, it reached hit@6 0.70 (baseline 0.40) and MRR 0.43. Off-the-shelf rerankers found more answers within the top 10 but ranked them lower, and were 2–20× slower. With 10 answerable questions, these are indicative results.

**Golden set**: 12 questions (10 single, 2 near-miss) over 5 papers, version 1. Questions drafted by Claude Code, reviewed by Nazeen Asif.

**Limits**:
- The set is small: 10 answerable questions, so one question moves hit@k by 10 points. Treat differences of one or two questions as noise.
- Retrieval only: answer quality, faithfulness and the LLM judge are future work, so those columns read "not measured".
- Every row gates on the top vector score; near-misses gated means the question would be refused without a model request.
- Each row is one deterministic run on this CPU; latency excludes model loading.
