# Evaluation results

Generated by `python -m evaluation report` from `eval/results/`, `eval/experiments.json` and `eval/golden.json`. Do not edit by hand.

**Conclusion**: Adding the paper title and section to each passage before embedding gave the best ranking (MRR 0.31 → 0.41, hit@1 0.20 → 0.30) at no runtime cost. Off-the-shelf rerankers found more answers within the top 10 but ranked them lower, and were 2–20× slower. With 10 answerable questions, these are indicative results.

- Each row is one deterministic run on this CPU; latency excludes model loading.
